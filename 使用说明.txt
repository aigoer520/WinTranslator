WinTranslator v1.7.5
【v1.8.0 新版】（先看这段）
这次是翻译和查词的「来源」大扩容，界面改动都先出过静态图、经你确认后实施。

一、查词有 10 家词典了
- 点词查词小窗顶部多了来源切换条：有道、必应、剑桥、韦氏、Urban、Vocabulary、彩云、汉典、国语、两岸，一次看一家，点哪家查哪家；查过的结果会记住，切换回来不用重新联网。
- 默认不用管：查英文词落有道，查中文词落汉典；在设置→翻译接口里可以改默认词典，手动点选过的来源也会被记住。
- 哪家查不到或连不上，小窗里会直接写明原因（比如「未收录」「未配置」），不会偷偷换一家糊弄你。剑桥要是被拦，小窗里有「在浏览器打开剑桥词典」的入口。
- 先交代实测情况（我方测试网络下）：有道、剑桥、Urban、Vocabulary、汉典、国语、两岸都实测查到了；必应在我方网络下被必应回了「无结果页」，没查通（标未双确认，你真机上以实际为准）；韦氏和彩云词典要填自己的 Key 才能用（见第三条）。

二、翻译引擎变多了
- 引擎条还是一行：原来的自动、有道、必应、AI、谷歌、MyMemory 都在，新添的排在后面。
- 免费新引擎默认就在条上：Edge 翻译、Apertium、Reverso。注意：Apertium 只擅长欧洲语言之间互译（英↔西/法/德等），拿它翻中英会报错，属正常；Edge 翻译和 Reverso 在我方测试环境一个端点异常、一个时通时断（未双确认），真机点不动也别奇怪，换回有道/必应即可。
- 选了哪个引擎就用哪个：新引擎失败会在状态栏明确报错，不会偷偷换成别家。

三、设置→翻译接口：填自己的 Key 解锁更多引擎
- 新页签「翻译接口」：百度翻译、DeepL、彩云小译、小牛翻译、有道智云、阿里翻译、腾讯翻译君、火山翻译、DeepLX、韦氏词典，每家一行，点开填 Key，再点「测试连接」验证。填了哪家，哪家才出现在引擎条/词典条里。
- 申请都是免费注册、都有免费额度（各家政策会变，以官网为准）：百度→百度翻译开放平台（fanyi-api.baidu.com，建应用拿到 App ID 和密钥）；DeepL→deepl.com 的 API 计划（免费版 Key 以 :fx 结尾）；彩云→彩云科技开放平台（dashboard.caiyunapp.com，建应用拿 Token）；小牛→niutrans.com（控制台拿 API Key）；有道智云→ai.youdao.com（建应用拿应用 ID 和密钥）；阿里→阿里云机器翻译控制台（mt.console.aliyun.com，用阿里云 AccessKey）；腾讯→腾讯云机器翻译（console.cloud.tencent.com/tmt，用腾讯云 SecretId/SecretKey）；火山→火山引擎（console.volcengine.com 的访问密钥）；韦氏→dictionaryapi.com 注册拿 Collegiate Dictionary 的 API Key；DeepLX 是自部署服务（GitHub 上有开源项目），部署后把地址填进来。
- 密钥只加密存在本机设置里，不进云同步包，别人拿到你的同步仓库也看不到。
- LibreTranslate 和 Lingva：官方/默认公共实例目前一个要付费 Key、一个不稳定，所以默认不出现在引擎条里；你要是自建了实例，把地址填到「免费接口地址」里，它们就会出现。

四、翻译交叉核对（新功能，默认关）
- 在设置→翻译接口底部打开。开启后，每次翻译完成会再用另一家免费引擎在后台翻一遍，逐句比对：数字对不上、否定词丢失、两家译法差太多，都会标出来——首页在状态栏给一句摘要，截图翻译在组合窗的对照卡上方列明哪句存疑、第二家是怎么译的。
- 还有「回译抽查」子开关（更慢，默认关）：只对已存疑的句子，把译文再翻回原文语言比对一次，多一道参考。
- 说清楚：核对只提示存疑，不自动改你的译文，也不显示「准确率百分比」——两家一致不等于译对了，两家不一致也不等于主译文错了，它是给你多一双眼睛。
